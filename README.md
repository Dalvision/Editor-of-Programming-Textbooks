Это GUI-программа открывает оцифрованные, в формат специального JSON-файла, программированные учебники. 

Если вы работали с этим видом учебников, то вы явно уставали от фраз в нём, по типу: "Продолжайте чтение с рубрики ..." - дальше, утамительный поиск нужной страницы, и так всю главу. С этой программой, изучив особенность формата JSON-файлов для этой программы на приложеном примере и почитав код, вы можете оцифровать один из своих учебников.
